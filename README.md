# Feira de Empreendedorismo

Site estático da turma da Escola Adventista da Pampulha.

- `index.html`: conteúdo da página
- `styles.css`: estilos responsivos
- `script.js`: menu, animações e links de pedido pelo WhatsApp

Para trocar o número dos pedidos, atualize `whatsappNumber` em `script.js` usando o código do país, DDD e número, sem o sinal `+`.
